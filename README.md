# ✂️ Estilo Livre — Barbearia

Projeto desenvolvido para praticar o uso do **Bootstrap 5**, utilizando seu sistema de Grid e componentes prontos para criação de uma página web responsiva.

## 📌 Sobre o projeto

A **Estilo Livre** é uma barbearia fictícia criada para este exercício.

O site apresenta uma interface moderna e responsiva com as seguintes seções:

* 🏠 Home
* 👥 Sobre Nós
* 💈 Serviços
* 💬 Depoimentos
* 📩 Contato

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap 5

## 📦 Componentes Bootstrap utilizados

O projeto utiliza diferentes recursos do Bootstrap:

* Navbar responsiva
* Grid System
* Cards
* Carousel
* Formulários
* Buttons
* Classes utilitárias
* Containers
* Rows e Columns
* Classes responsivas

## 📱 Responsividade

O layout foi desenvolvido utilizando o sistema de Grid do Bootstrap para adaptar o conteúdo a diferentes tamanhos de tela.

### Desktop

Os serviços são apresentados em quatro colunas.

### Tablet

Os serviços são apresentados em duas colunas.

### Celular

Os serviços são apresentados em uma coluna.

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/estilo-livre-bootstrap.git
```

Entre na pasta:

```bash
cd estilo-livre-bootstrap
```

Abra o arquivo `index.html` no navegador ou utilize o **Live Server** no Visual Studio Code.
